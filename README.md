# AI Chat

Kalitsiz, bepul AI suhbatdosh — Pollinations API asosida.

## Imkoniyatlar

- Ro'yxatdan o'tish va API kalitisiz ishlaydi
- 4 ta model: OpenAI, OpenAI Fast, Mistral, Llama
- Suhbatlar tarixi `localStorage`da saqlanadi
- Markdown, ro'yxatlar va kod bloklarini chiroyli ko'rsatish
- Javobni to'xtatish va qayta urinish
- O'zbek, ingliz va rus tillari
- Yorug'/tun rejimi

## Texnologiyalar

React · TypeScript · Vite · Tailwind CSS · Pollinations API · localStorage

## Ishga tushirish

```bash
npm install
npm run dev
```
